This is the operational checklist for the breeder/business owner. Code and technical SEO are
already largely complete. The remaining work builds real local authority and customer trust.

## P0 — finish Google Business Profile

- [ ] Complete GBP verification — **in progress as of September 19, 2026**.
- [ ] Use the real-world business name: `Exotic Bulldog Legacy`.
- [ ] Select the most accurate primary category available; do not add unrelated categories for
      keywords.
- [ ] Add the canonical website and one primary phone number.
- [ ] Add accurate business hours and appointment information.
- [ ] Configure only cities/areas the business genuinely serves.
- [ ] If customers are not served at the residential address, keep the street address hidden and
      use the correct service-area model.
- [ ] Add a factual description without promotional spam, unsupported claims, or links.
- [ ] Upload real logo, cover, breeder, parent-dog, puppy, pickup, and customer-approved alumni
      photos.
- [ ] After verification, add a UTM-tagged website link so GBP visits can be measured in GA4.

## P1 — genuine review process

- [ ] Generate the official Google review link and QR code after GBP verification.
- [ ] Create a simple post-purchase review request message.
- [ ] Ask only genuine customers; never buy reviews or offer incentives for positive reviews.
- [ ] Ask permission before reusing customer names, locations, photos, or messages on the website.
- [ ] Reply briefly and personally to every genuine Google review.
- [ ] Track request date, response, permission for website use, and customer city in a private
      owner-managed list.

## P1 — canonical NAP and profiles

- [ ] Owner approves the canonical public identity:
      `Exotic Bulldog Legacy` / `Falkville, Alabama` or the approved service-area presentation /
      one phone number / `https://exoticbulldoglegacy.com/`.
- [ ] Confirm the same public information on Facebook and Instagram.
- [ ] Create or correct Bing Places and Apple Business Connect when applicable.
- [ ] Add 1–3 legitimate local, pet, or breeder directory profiles that accurately fit the
      business.
- [ ] Do not publish the private pickup address in directories if it is intentionally hidden.

## P1 — real authority and partnerships

- [ ] Identify genuine veterinarians, groomers, trainers, transport providers, kennel clubs,
      events, or local pet businesses with an existing relationship.
- [ ] Seek a small number of accurate profile links, partner mentions, interviews, or event
      listings.
- [ ] Use AKC, club, association, rescue, veterinary, licensing, or certification claims only when
      the owner can document that they apply.
- [ ] Never buy bulk backlinks, directory packages, or DA/DR boosts.

## P1 — breeder trust evidence

- [ ] Organize available parent/litter DNA, OFA, veterinary, registration, and health records.
- [ ] Decide which records can be shown publicly and which should be shared privately with a
      qualified buyer.
- [ ] Keep claims litter-specific: do not state that every parent or puppy has the same testing,
      registration, guarantee, or clearance unless that is verified.
- [ ] Collect original parent-dog, puppy-development, living-condition, pickup, and alumni photos.
- [ ] Maintain clear authorship and breeder experience on health and care content.
- [ ] Obtain owner approval for medical, legal, pricing, delivery, guarantee, and partnership
      statements before publication.

## P2 — measurement and controlled improvement

- [ ] After October 6, compare a complete 28-day GSC period with the preceding 28 days.
- [ ] Review local/commercial pages separately from articles.
- [ ] Review branded and non-branded queries separately.
- [ ] Combine GSC with GA4 and GBP metrics; impressions are not unique visitors.
- [ ] Measure visits to `/puppies`, puppy views, Contact, Call/WhatsApp, video-call requests,
      Reserve, checkout starts, and successful deposits.
- [ ] Select one page at a time for improvement only when the thresholds in
      [`SEO_PLAN.md`](../planning/SEO_PLAN.md) are met.
- [ ] Record each meaningful checkpoint as a new dated `SEO-GSC-report-YYYY-MM-DD.md` file.

## P2 — unresolved content decisions

- [ ] Choose one consistent strategy for unavailable puppy profiles:
  - keep useful sold/alumni pages indexable as genuine portfolio pages; or
  - remove low-value profiles from the sitemap and use `noindex` consistently.
- [ ] Monitor High-Carb, Potty Training, and Ultimate Guide through the next complete window before
      changing titles or content.
- [ ] Publish new content only when it answers demonstrated buyer demand or adds real breeder
      experience, verified facts, original media, and a useful next step.

## Do not repeat

- Do not request indexing repeatedly for already indexed articles.
- Do not resubmit a healthy sitemap without a real discovery problem.
- Do not create batches of near-identical city or state pages.
- Do not rewrite all titles, descriptions, or articles based on one low-volume week.
- Do not treat FAQ schema as a guaranteed rich-result feature.
- Do not copy legal, veterinary, licensing, genetic, or pricing claims from competitor/research
  documents without owner verification.
